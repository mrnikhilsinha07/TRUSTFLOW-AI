# TRUSTFLOW AI

**An AI-powered payment risk analysis and payment management assistant.**

TRUSTFLOW AI is a project developed for the PayPal AI Hackathon. It aims to help users identify potential warning signs in payment requests, understand payment risks, and make informed decisions before authorizing transactions.

## Current Features

- AI-powered payment risk analysis.
- Natural-language explanations of potential warning signs.
- Recommendations for verifying suspicious payment details.
- Local AI inference using Ollama.
- FastAPI backend.
- Interactive API documentation.
- Payment execution is not currently implemented.

## Technology Stack

- Python 3.13
- FastAPI
- Uvicorn
- Ollama
- Qwen3 1.7B

## Prerequisites

Install the following before running the application:

- Python 3.13 or a compatible Python version.
- Git.
- Ollama.
- The `qwen3:1.7b` model.
